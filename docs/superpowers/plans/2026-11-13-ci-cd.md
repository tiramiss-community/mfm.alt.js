# CI/CD Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** PRの検証とChangesetsによるバージョン更新、Release公開時のnpm publishを整備する。

**Architecture:** CI、version、publishの3つのworkflowに分ける。既存のpnpm scriptsを実行し、publish前にも検証する。

**Tech Stack:** GitHub Actions, Node.js 24, pnpm 12.14.0, Changesets 2 / action v1.

**Spec:** ../specs/2026-11-13-ci-cd-design.md

## Global Constraints

- 公開名は `@tiramiss-community/mfm.alt.js`、base branchはmain。
- GitHub Releaseの公開でpublish。バージョン更新PRへのマージではpublishしない。

## Review Focus

- fork PRには書き込み権限とSecretsを渡さない。
- 自動作成PRでもCIが発動するトークンを使う。
- タグとversionが異なるReleaseはpublish前に失敗する。
- prereleaseはnextへ公開する。
- Changesetsによる更新後もfrozen lockfileでインストールできる。
